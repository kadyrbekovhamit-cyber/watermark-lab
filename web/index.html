ИССЛЕДОВАНИЕ ПРОИСХОЖДЕНИЯ ТЕКСТА

Метка в словах.

Проверка открытой схемы SynthID-Text с известным ключом. Разбор текста — с ясными границами вывода.

Проверка метки Claude пока недоступна

Ключ и точные настройки Claude не опубликованы. Официальный детектор находится в закрытом предварительном доступе. Этот инструмент не выдаёт процент «написано Claude».

Что можно установить по тексту

0 символов

Проверка покажет объём и невидимые Unicode-символы. Такие символы встречаются и в обычном тексте; это не свидетельство использования ИИ. Исходный текст не изменяется.

Одинаковый детектор. Три источника токенов.

Искусственные последовательности по 128 токенов. Это контрольные данные нашего генератора, не ответы Claude. Проверка использует 8 публичных демонстрационных ключей и отдельную выборку из 199 примеров без метки.

Отрицательный результат третьего теста не означает, что метки нет. Детектор ищет только сигнал своего профиля.

Проверка экспортированных токенов

Загрузите JSON с token_ids, tokenizer_id, profile и, при наличии, calibration. Нужны точный токенизатор и совместимый профиль генератора. Поддерживается только зафиксированная открытая реализация; профиля Claude здесь нет.

Без подходящей контрольной выборки будет показан балл, без заключения об обнаружении. Формат и пример — в README.md и evidence/.

Оценка последовательных токенов

Высота столбика — средний g-балл токена по ключам. Серые столбики исключены как повторный контекст. Это не вероятность авторства.

Невидимые и специальные символы

    Как устроена проверка

    1

    Контекст + ключ

    Короткая последовательность токенов и ключ определяют двоичные g-оценки.

    2

    Выбор следующего токена

    Генератор меняет распределение допустимых вариантов. В тексте накапливается статистический сигнал.

    3

    Проверка по тому же профилю

    Детектор пересчитывает оценки и сопоставляет балл с независимой выборкой без метки.
